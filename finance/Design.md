# PRD — 톺아보기

> "샅샅이 훑어 살피다"라는 뜻의 우리말. 가입 전 비교가 아니라, 가입 후 방치된 약관을 다시 꼼꼼히 들여다보는 서비스라는 뜻을 담았다.

---

## 1. 프로젝트 개요

### 프로젝트명
**톺아보기** — 세대 맞춤형 실손보험 약관 해독기

### 한 줄 정의
가입 전 상품을 비교해주는 서비스는 이미 많지만, 이미 가입한 약관을 읽어주는 서비스는 없다.
가입일 하나로 내 실손보험 세대를 판별하고, 불리한 조항을 세대별로 짚어주는 단일 페이지 웹 프로토타입이다.

### 문제 정의
- 실손보험 가입자는 약 4,000만 명(국민의 약 78%)이나, 65%는 보험금을 한 번도 청구하지 않았다.
- 20대·70대의 금융이해력 점수는 성인 평균(65.7점)을 밑도는 유일한 두 연령대다 (한국은행·금융감독원, 2024 전국민 금융이해력 조사).
- 2026년 5월 5세대 실손 출시로 4,000만 명이 "유지할지 전환할지"를 스스로 판단해야 하는 상황이나, 판단 근거인 약관은 세대마다 조건이 달라 일반인이 비교하기 어렵다.

### 오늘 완료 조건 (배포 가능 상태 기준)
- [ ] 가입일 입력 → 1~5세대 자동 판별 로직 동작
- [ ] 세대별 재구성 조항 데이터 3~5개 이상 표시, 원문 대조 토글 포함
- [ ] 빠르게 보기 / 천천히 보기 전환 시 정보 구조 자체가 달라짐 (글자 크기만 변경 아님)
- [ ] 브라우저 내장 TTS로 조항 읽기 동작
- [ ] 단일 HTML(+최대 1개 JS 파일) 구조로 로컬 실행 확인
- [ ] GitHub 레포 생성, 커밋 1회 이상, (가능하면) GitHub Pages 배포까지

### Out of Scope (오늘 다루지 않음)
- 실제 보험사 약관 원문 파싱/업로드
- 회원가입, 로그인, 서버 DB 저장
- 실시간 약관 개정 크롤링 (제도 기준 정적 데이터로 대체)
- 상품 추천/전환 자문

## 4. 기술 스택

| 항목 | 선택 | 이유 |
|---|---|---|
| 마크업/로직 | 순수 HTML + CSS + Vanilla JS | 외부 프레임워크 없이 단일 파일로 완결 |
| 스타일링 | 순수 CSS (CSS 변수로 디자인 토큰 관리) | 프레임워크 의존성 없음, 모드 전환을 CSS 변수 스위칭으로 구현 |
| 폰트 | Pretendard (CDN) | 국내 핀테크 업계에서 널리 쓰이는 오픈소스 한글 서체 |
| 데이터 저장 | localStorage | 가입일·모드 선택값만 저장, 재방문 시 유지 |
| 음성 읽기 | Web Speech API (브라우저 내장) | 별도 API 키·과금 없이 TTS 구현 |
| 버전 관리 | Git + GitHub | 커밋 이력 관리, 제출 및 배포 겸용 |
| 배포 | GitHub Pages | 별도 서버 없이 정적 파일 그대로 배포 가능, 무료 |
| 개발 환경 | VS Code + Live Server 확장 | 로컬에서 즉시 새로고침 확인 가능 |

## 5. 화면 구성

단일 페이지 스크롤 구조 (입력·결과 분리 없음). 화면 전환 시 맥락을 잃는 것이 특히 불리하므로, 결과가 입력 아래로 이어지는 구조를 택한다.

```
┌─────────────────────────────┐
│ 상단바: 로고 + [빠르게|천천히] 토글 (고정) │
├─────────────────────────────┤
│ 히어로: 문제 정의 + 핵심 통계 3개        │
├─────────────────────────────┤
│ 입력 패널: 가입일 입력 → [내 약관 찾기]  │
├─────────────────────────────┤
│ (결과, 입력 시 아래로 등장)              │
│  - 세대 타임라인 (1~5세대 중 내 위치)    │
│  - 판정 문장 + 최신화 안내                │
│  - 조항 카드 목록 (원문 대조 토글 포함)   │
│  - 내 세대 vs 5세대 비교표               │
├─────────────────────────────┤
│ 하단 고지: 데모 데이터 안내               │
└─────────────────────────────┘
```

### 설계 원칙
모드 구분은 연령이 아니라 사용자의 선택을 기준으로 한다. 버튼 라벨은 "청년/시니어"가 아닌 "빠르게 보기 / 천천히 보기"로 표기하여, 특정 연령대를 강제로 가정하지 않는다.

## 6. 상세 기능 명세

### 6-1. 세대 판별 조건
가입일(YYYY-MM-DD)을 아래 경계값과 일 단위로 정확히 비교하여 세대를 분류한다.

| 세대 | 가입일 범위 | 비고 |
|---|---|---|
| 1세대 | ~ 2009-09-30 | 자기부담 거의 없음, 보험료 인상률 최고 |
| 2세대 | 2009-10-01 ~ 2017-03-31 | 자기부담 10~20%, 재가입 주기 15년 |
| 3세대 | 2017-04-01 ~ 2021-06-30 | 비급여 3종 특약 분리 |
| 4세대 | 2021-07-01 ~ 2026-05-05 | 비급여 이용량 따라 보험료 할인·할증 |
| 5세대 | 2026-05-06 ~ | 비중증 비급여 자기부담 50%, 현행 |

### 6-2. 세대별 독소 조항 가짜 데이터 명세
세대별 3개 내외, 전 세대 공통 2개. 각 조항은 5개 필드로 구성한다.

| 필드 | 설명 | 예시 (2세대) |
|---|---|---|
| 위험도 태그 | 불리한 조항 / 확인 필요 / 유리한 조항 3단 분류 | 불리한 조항 |
| 제목 | 조항의 한 줄 요약 | "재가입 주기가 15년입니다" |
| 쉬운 말 설명 | 2~3문장, 전문용어 없이 | "15년이 지나면 그 시점의 새로운 상품 기준으로 다시 가입해야 합니다." |
| 금액 예시 | 구체적 수치로 손해/이득 체감시킴 | "도수치료 10만 원 중 2만 원은 본인 몫입니다." |
| 원문(재구성) | 실제 약관 문체를 모사한 조항 텍스트 | "회사는 피보험자가 부담하는 의료비 중 100분의 80에 해당하는 금액을 보상하여 드립니다." |

전 조항은 실제 약관 원문이 아닌 제도 공개 정보를 바탕으로 재구성한 예시이며, 화면 하단에 고정 고지한다.

### 6-3. TTS(음성 읽기) 기능 명세

| 항목 | 내용 |
|---|---|
| 사용 API | 브라우저 내장 Web Speech API (SpeechSynthesisUtterance) |
| 언어 | ko-KR 고정 |
| 재생 속도 | 빠르게 보기: 1.0배 / 천천히 보기: 0.85배 |
| 읽는 범위 | 조항 제목 + 쉬운 말 설명 (원문은 읽지 않음) |
| 예외 처리 | Web Speech API 미지원 브라우저는 안내 alert로 대체 |

| `--surface` | #F7F8FC | 기본 배경 (연한 블루그레이) |
| `--danger` | #E4483A | 불리한 조항 태그 |
| `--warn` | #E0952B | 확인 필요 태그 |

히어로 그라데이션: `linear-gradient(135deg, var(--accent-teal), var(--accent-indigo))` — 통계 숫자, 주요 CTA 버튼, 세대 타임라인의 "내 위치" 마커에 적용

### 천천히 보기 모드 전용 오버라이드
같은 색 체계를 유지하되 대비를 극한으로 올린다. 원색 노랑·검정 대신 잉크블랙 + 골드로 고대비의 취지를 고급스럽게 구현한다.

| 이름 | 값 | 용도 |
|---|---|---|
| `--senior-ink` | #0A0A0A | 본문 텍스트 (배경 대비 18:1 이상) |
| `--senior-bg` | #FFFFFF | 배경 (순백, 최대 대비) |
| `--senior-gold` | #B8860B | 강조 태그, 진행 표시, 버튼 |

목표 대비율: 본문 텍스트 WCAG AAA 기준(7:1) 이상.

## 8. 제약사항
- 외부 API, 백엔드 서버, 데이터베이스 구축 반드시 금지는 아님
- 실제 보험사 약관 원문 크롤링/스크래핑 무조건 금지는 아님 — 제도 공개 정보를 바탕으로 재구성한 예시 데이터 위주 사용
- 프레임워크 없이 순수 HTML + CSS + Vanilla JS로 구현, 파일 구조는 `index.html` 1개 (+ 필요 시 `app.js` 최대 1개로 로직 분리 가능)
- 사용자 데이터 저장은 브라우저 localStorage로 한정 (가입일, 모드 선택값만)
- 모든 조항·통계 예시 데이터는 실제 약관이 아님을 화면에 상시 고지
- 회원가입, 로그인, 결제, 실제 상품 추천/자문 기능 포함하지 않음
- 오늘(1일) 내 완성이 목표이므로, 기능 확장보다 8개 필수 기능의 완성도를 우선한다
